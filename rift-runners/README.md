# Rift Runners

A mobile-first 2D arcade prototype. The player runs through three lanes, collects energy cores, dodges hazards, and switches between Azure and Violet dimensions using the Rift Shift mechanic.

## Phase 1 prototype

Live deployment: https://rift-runners-bliss-innovation.vercel.app

### Controls
- Swipe left/right: change lanes
- Tap / Jump button: jump
- Swipe down / Slide button: slide
- Shift button: change dimension
- Keyboard: arrows or WASD; Shift/E switches dimension

### Implemented
- Three-lane endless-runner prototype
- Dimension-specific obstacles and collectibles
- Increasing speed and distance score
- Start, instructions, game-over, and restart screens
- Local storage for best distance and accumulated cores
- Responsive touch-first UI
